How did using Figma designs as references affect your coding process?


Having the Figma design made it a lot easier to figure out what things were supposed to look like instead of just guessing. It gave me a clear target for spacing, font sizes, and colors, so I wasn't just winging the layout.

What challenges did you encounter when aligning your code with the design specifications?

Matching the exact padding and margins took some trial and error, especially getting the card to center properly on the page and making sure the hover effects on the title behaved correctly without breaking the layout.

How can the feedback and community resources on Frontend Mentor help you improve as a developer?

Seeing how other people solved the same exact challenge is super helpful because it shows you different ways to structure your code or cleaner CSS tricks you might not have thought of yourself.
